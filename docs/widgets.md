# Widgets

## System

Shows OS, host, kernel, uptime, and other system information. Configure which fields appear in Settings.

## CPU

Shows aggregate CPU usage and per-core breakdown.

## Memory

Shows RAM and swap usage with bytes and percentage.

## Disk

Shows disk usage for each detected drive. Configure visibility per-disk in Settings.

## Network

Shows current download/upload bandwidth usage.

## Spectrum

Real-time audio frequency spectrum visualizer. Requires PulseAudio.

## Ring

Circular audio visualizer. Requires PulseAudio.

## Clock

Analog or digital clock with configurable font, color, seconds, 12/24h display, and layout.

## Date

Date display with weekday toggle and format selection (long/short/numeric).

## Panel

Container widget that arranges child widgets horizontally or vertically.

## Plugin

Custom plugin widget. See Plugins documentation.
